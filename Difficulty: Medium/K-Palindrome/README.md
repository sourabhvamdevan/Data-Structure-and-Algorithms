<h2><a href="https://www.geeksforgeeks.org/problems/find-if-string-is-k-palindrome-or-not1923/1?page=4&category=Dynamic%20Programming&difficulty=Medium&sortBy=submissions">K-Palindrome</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">You are given a string <strong>s</strong> and an integer <strong>k</strong>.</span></p>
<p><span style="font-size: 18px;">A string is called a <strong>k-palindrome</strong> if it can be transformed into a palindrome by removing <strong>at most</strong> <strong>k</strong> characters.</span></p>
<p><span style="font-size: 18px;">Determine whether the given string <strong>s</strong> is a k-palindrome. Return <strong>true </strong>if it is a k-palindrome; otherwise, return <strong>false</strong>.</span></p>
<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>
<pre><span style="font-size: 18px;"><strong>Input:</strong> s = "abcdecba", k = 1
<strong>Output:</strong> true
<strong>Explaination:</strong> By removing 'd' or 'e' we can make it a palindrome. Therefore answer is true for this test case.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input:</strong> s = "abcdefcba", k = 1
<strong>Output:</strong> false
<strong>Explaination:</strong> By removing a single character we cannot make it a palindrome.</span></pre>
